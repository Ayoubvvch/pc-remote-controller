# 💻 PC Remote Controller (Android & Windows)

تطبيق أندرويد خفيف وسريع جداً (Native Kotlin) للتحكم بالحاسوب عبر شبكة الواي فاي المحلية عن طريق واجهة محادثة (Chat) وأزرار سريعة.

---

## 🌟 المميزات (Features)

- **💬 واجهة محادثة ذكية وخفيفة (Chat UI):** تكتب الأمر كأنك تتحدث مع حاسوبك ويرد عليك فوراً بالنتيجة.
- **⚡ أزرار سريعة (Quick Action Chips):**
  - 💤 **Sleep:** وضع السكون للحاسوب فوراً.
  - 🔒 **Lock:** قفل شاشة الحاسوب.
  - ⚡ **Hibernate:** وضع الإسبات.
  - 🛑 **Shutdown:** إيقاف التشغيل مع مهلة وإمكانية الإلغاء.
  - 🔄 **Restart:** إعادة تشغيل الحاسوب.
  - 🚫 **Cancel:** إلغاء الإيقاف المجدول.
  - 🔇 **Mute:** تبديل كتم الصوت.
  - ℹ️ **Status:** فحص حالة الحاسوب ومواصفاته ووقت التشغيل.
- **⚙️ إمكانية تخصيص الـ IP:** تغيير عنوان الـ IP والمنفذ بسهولة من داخل التطبيق.
- **🚀 بناء تلقائي (GitHub Actions):** استخراج ملف الـ APK تلقائياً عبر GitHub Actions بمجرد رفع الكود.

---

## 🛠️ طريقة التشغيل على الحاسوب (Windows Server)

1. ادخل لمجلد `server/`.
2. شغّل `start_server.bat` (أو `start_silent.vbs` للتشغيل الصامت في الخلفية).
3. سيعمل السيرفر على المنفذ `5050` وسيعرض لك عناوين الـ IP الخاصة بحاسوبك.

---

## 📱 تطبيق الأندرويد (Android App)

- مبني بلغة Kotlin الخام (بدون أي محركات ثقيلة، حجم الـ APK خفيف جداً ~3MB، وسرعة استجابة فورية).
- يتم تجميعه تلقائياً بواسطة GitHub Actions عند كل دفع للكود (Push).
